QR-Code & Barcode Scanner

Ergebnis: Noch kein Code erkannt.
Klicke auf „Scanner starten“ und erlaube den Kamerazugriff.
Einfache Browser-App zum Einlesen von QR-Codes und Strichcodes mit der Kamera.

Erkannte Codes:
QR-Code, EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, ITF, PDF417, Data Matrix, Aztec und weitere gängige Formate.

Nach dem ersten Laden funktioniert die App auch offline.
